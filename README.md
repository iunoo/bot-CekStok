# Bot Cek Stok

Bot Telegram untuk cek stok barang menggunakan Node.js. Fitur utama:
- Cek stok dengan perintah `/s <nama barang>`
- Upload data stok/pesanan via file Excel untuk admin
- Verifikasi kredensial untuk user

## Cara Install
1. Clone repository: `git clone https://github.com/iunoo/bot-CekStok`
2. Install dependensi: `npm install`
3. Atur `.env` dengan kredensial (lihat `.env.example` kalau ada)
4. Jalankan bot: `node index.js`
